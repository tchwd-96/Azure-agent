# TCHWD Azure Manager — Azure Agent

Repositorio de desarrollo para la integración de Microsoft Azure en Techno World Solutions (TCHWD).

## Estado
- Fase: inicialización del repositorio.
- Responsable funcional propuesto: `ld-dev`.
- Control: Dirección General `@tchwd-dir`.
- Autorización: desarrollo aislado y consultas de solo lectura; sin despliegues, cambios de producción ni gastos.
- Referencias operativas: SEC-001, WIP-005 y registro Programados.

## Objetivos
Construir un panel de administración Azure, una API FastAPI de lectura, inventario de recursos, consulta de costes y telemetría, y una integración de desarrollo asistido con Codex.

## Seguridad
No almacenar claves API, tokens, secretos, credenciales ni datos sensibles en este repositorio. Toda acción externa, cambio de permisos, despliegue o generación de gastos requiere autorización expresa de Dirección.

## Desarrollo
Los cambios técnicos deben prepararse en ramas independientes y someterse a revisión antes de fusionarlos. La conexión real con una suscripción Azure está pendiente de verificación y autorización específica.
